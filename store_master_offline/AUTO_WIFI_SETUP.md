# StoreMaster — Automatic Shared Wi‑Fi Mode

هدف این نسخه: اتصال Windows و Android در یک Wi‑Fi با Shared License بدون اجرای اسکریپت دستی.

- Windows: One-time UAC + automatic firewall rules.
- Android: automatic LAN multicast support + discovery.
- One discovered Shared store: automatic join.
- Multiple stores: user selects one store.
- After join: signed license + store configuration + users + SQLite business data sync.
- Bidirectional ongoing sync through the Windows Hub.
