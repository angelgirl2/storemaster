# Video Splash

Windows, Linux, macOS and Android now use `VideoStoreSplash`.
`VideoPlayerMediaKit.ensureInitialized` is enabled for Windows too.
If the video backend or asset fails, startup recovers after a short bounded timeout; the static splash is not used.

Windows asset: `assets/videos/splash_windows2.mp4`
Android/mobile asset: `assets/videos/splash_android.mp4`
