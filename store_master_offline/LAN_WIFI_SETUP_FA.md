StoreMaster LAN setup

Windows and Android must be connected to the same Wi-Fi and the Wi-Fi must permit device-to-device traffic.

On Windows, run as Administrator:
ops\allow_storemaster_lan.ps1

Then start StoreMaster Windows with a Shared license (ALL + STORE_SHARED). Open StoreMaster Android and choose the detected store under:
«انتخاب فروشگاه از همین Wi-Fi»

After selection, the Android device receives the signed shared license and the store snapshot. Then it shows the synchronized users for normal login.
